# Technical writing

Every document this mode covers needs the first seven parts. Read them in order before writing or reviewing; they are short, and skipping one drops a layer the others assume. Paths here are relative to this mode directory.

1. [Overview and the three top rules](part-01.md): read first, every time.
2. [Vary the rhythm](part-02.md): read before drafting.
3. [Pick the mode first (Diátaxis)](part-03.md): read before drafting a document or document set. PR descriptions and commit messages skip this layer.
4. [Write sentences to the reader (Google developer style)](part-04.md): read before drafting.
5. [Make statements load one at a time (STE rules)](part-05.md): read before drafting.
6. [Leave no sentence open to two readings (Global English)](part-06.md): read before drafting.
7. [Voice and repo specifics](part-07.md): read before drafting; it names the companion prose pass and the code-snippet rules.

Then:

- [Worked example](part-08.md): read when unsure how the layers combine on one paragraph.
- [Review checklist](part-09.md): read before finishing, and apply every item.
