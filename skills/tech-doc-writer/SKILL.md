# tech-doc-writer

Select writing, localization, or consistency review. Preserve the requested audience, source meaning, identifiers, and stopping point. Documentation review does not authorize rewriting code or publishing comments.

## Select a mode

- Translate or maintain localized README variants; preserve links and code and emphasize the current language in the selector. Read [the procedure](references/modes/readme-i18n/guide.md).
- Documentation consistency reviewer that checks alignment between code implementation and documentation. Read [the procedure](references/modes/review-doc-consistency/guide.md).
- Layered tech-doc-writer standard: Diátaxis structure, Google developer style sentences, STE instruction rules, Global English syntax. Read [the procedure](references/modes/technical-writing/guide.md).

Resource paths inside a mode are relative to that mode directory. Run its scripts from that directory or use absolute script paths, passing the target repository explicitly.
