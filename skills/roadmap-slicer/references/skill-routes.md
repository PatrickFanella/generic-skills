# Companion skills

These routes extend this procedure within the current task. Optional helpers apply only under the stated condition and do not widen authorization.

| Skill | Relationship | When to load it |
|---|---|---|
| `scope-grill` | optional | When an open product decision changes the breakdown and investigation cannot settle it. |
| `build-sequencer` | optional | When the plan lacks an ordered change sequence or acceptance criteria to slice from. |

Load a listed skill only if the current client has it installed. Open the
selected `SKILL.md` and its needed references, resolving resources from that
directory. If a skill is not installed, say so; do not guess a tool or load
the whole group. Reuse already
loaded skills to avoid cycles. Report unavailable required checks explicitly.
