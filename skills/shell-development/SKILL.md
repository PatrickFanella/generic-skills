# shell-development

Preserve argument boundaries, exit statuses, and cleanup ownership. Choose implementation, linting, or tests; an ordinary script edit does not require all three reference sets.

## Select a mode

- Master defensive Bash programming techniques for production-grade scripts. Read [the procedure](references/modes/bash-defensive-patterns/guide.md).
- Master Bash Automated Testing System (Bats) for comprehensive shell script testing. Read [the procedure](references/modes/bats-testing-patterns/guide.md).
- Master ShellCheck static analysis configuration and usage for shell script quality. Read [the procedure](references/modes/shellcheck-configuration/guide.md).

Resource paths inside a mode are relative to that mode directory. Run its scripts from that directory or use absolute script paths, passing the target repository explicitly.
